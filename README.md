# Stillpoint

A private, dependency-free emotion-regulation prototype built around FEEL → REGULATE → EXAMINE → RESPOND → LEARN.

## Run

Double-click `start.bat`, or open `index.html` directly in a browser. No account or installation is required.

Reflections are stored only in browser local storage on this device. The app includes onboarding, a nine-emotion library, intensity and activation checks, a high-activation grounding branch, facts versus assumptions, a legitimate-mistreatment branch, reframing, behavioral urges, adaptive responses, summaries, history, and recurring-pathway insights.

Stillpoint is a reflection aid, not medical advice, diagnosis, therapy, or crisis care.
